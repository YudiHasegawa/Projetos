# 📚 Estudos e Projetos da Faculdade

Repositório central para organizar códigos, exercícios e projetos desenvolvidos durante os estudos e a faculdade de Análise e Desenvolvimento de Sistemas.

## 📂 Projetos

* **Sistema de Estoque e Carrinho em Python** (`sistema_estoque.py`) — Aplicação no terminal para gerenciar categorias, estoque e carrinho de compras, praticando dicionários, funções, validações e tratamento de erros.

## ▶️ Como executar os projetos

1. Instale o Python 3
2. Baixe ou clone o repositório
3. Acesse a pasta do projeto desejado e execute o arquivo no terminal:

```text
python sistema_estoque.py

```
